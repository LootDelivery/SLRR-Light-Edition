SLRR Runtime TTF — исправление ориентации, MeasureText и настройка размера

Состав архива
-------------
StreetLegal_Redline_native_TTF_MODE1_UPRIGHT.exe
    Обновлённый EXE с runtime TTF backend.

Fonts/TTF.scale
    Начальное значение масштаба интерфейсного шрифта: 100 процентов.

JavaPatch/TTF_Font_Settings.patch
    Патч исходников Text.java и OptionsDialog.java для ползунка в меню игры.

TTF_BACKEND_SOURCE/ttf_backend_mode1_fixed.c
    Исходный код встроенного нативного backend-а.

Установка EXE
-------------
1. Сделайте резервную копию текущего StreetLegal_Redline_native.exe.
2. Поместите StreetLegal_Redline_native_TTF_MODE1_UPRIGHT.exe в корень игры.
3. Убедитесь, что Fonts/UI.ttf находится на прежнем месте.
4. Скопируйте Fonts/TTF.scale из архива в папку Fonts.

Что исправлено в backend-е
--------------------------
- Устранён вертикальный переворот глифов: строки GDI bitmap копируются в atlas в исходном порядке.
- Исправлен порядок параметров GfxDevice::MeasureText. Правильный native-вызов: (this, text, scale). Прежняя сборка трактовала scale как указатель на строку и падала с access violation.
- Масштаб применяется одинаково при DrawText и MeasureText, поэтому ширина и выравнивание синхронизированы.
- Нативный backend периодически перечитывает Fonts/TTF.scale во время работы игры. Перезапуск не требуется.
- Логирование ограничено первыми несколькими вызовами, чтобы лог не разрастался на сотни тысяч строк.

Ползунок в настройках игры
--------------------------
Патч рассчитан на текущие исходники репозитория LootDelivery/SLRR-JAVAS.

1. Распакуйте архив.
2. Перейдите в корень своего клона SLRR-JAVAS.
3. Выполните:

   git apply путь/к/JavaPatch/TTF_Font_Settings.patch

4. Перекомпилируйте Java-скрипты обычным способом. В меню Options есть пункт DEBUG COMPILE ALL JAVAs.
5. Откройте OPTIONS -> ADVANCED GAME OPTIONS -> INTERFACE FONT SCALE.

Диапазон ползунка: 60–150%. Значение по умолчанию: 100%. Оно сохраняется в Fonts/TTF.scale и подхватывается нативным renderer-ом без перезапуска.

Без Java-патча размер можно менять вручную: откройте Fonts/TTF.scale и укажите целое число от 60 до 150. Например, 125 означает 125 процентов.

Примечания
----------
- UI.ttf не включён: используется внешний шрифт пользователя.
- Внешних DLL-хуков нет.
- frontend.rpk, SCX, TGA и PNG-ресурсы не изменяются.
- Цвет текста по-прежнему берётся из штатного D3DCOLOR (0xAARRGGBB); новая настройка размера не меняет цветовые вызовы TUFA.
- Сборка прошла статическую проверку PE и проверку дизассемблирования MeasureText. Саму игру в Windows в этой среде запустить нельзя, поэтому новую сборку нужно проверить у себя.
