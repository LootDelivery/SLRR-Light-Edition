# SLRR mods

This folder contains isolated source-level mod projects for Street Legal Racing: Redline.

Each mod should keep its own:
- source files mirroring their final SLRR script paths;
- integration patches against stock game scripts;
- installation and rollback instructions;
- notes about which game build was actually tested.

Compiled TUFA `.class` files should generally not be committed until the target game build is fixed and tested.
